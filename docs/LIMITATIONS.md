# Known limitations

SceneForge is an independently authored early preview. Full Borumi feature, file-format, visual and performance parity is **not achieved**. Keep original source footage and review your output.

| Area | Current boundary |
| --- | --- |
| Recording | Screen/window/region, separate sources, countdown, floating script/camera controls, capture border and take review are implemented. Earlier short recordings passed decode and sampled host-window exclusion; another region take had silent system audio and unverified content. Complete four-source/region capture acceptance for the final package, long-device synchronization and every-frame exclusion remain open. A region covers one display only. |
| Scenes and saved takes | Scene cards retain attempts, replace matching sources, keep sequential takes, overlap Record over, archive, and reorder/delete scenes. Scene reordering splits boundary-spanning clips, captions and effects while retaining source timing; exact native linked-take behavior still differs. Project metadata and local files are durable, but project JSON is not a portable media archive. Exact Borumi linked-take behavior is not reproduced. |
| Script and teleprompter | Plain scene text, caret split/merge, mirroring and local voice following are available. Full rich text, independent external-display presentation policies and Elgato controls remain absent. |
| Timeline | Multi-selection, vertical layer dragging, blade, split, trim, clipboard, edge snapping, ripple deletion, transcript deletion and configurable shortcuts are available. Custom layers support adding, renaming and removal with clips retained; automatic magnetic ripple insertion remains open. Native linked groups and complex source routing/group ripple semantics remain incomplete. Clipboard is internal. Untimed transcript text selects a whole caption. Waveforms are bounded 8kHz source envelopes, not sample-accurate loudness meters. |
| Import and compatibility | Supported Borumi 0.32.0 data can be imported without changing originals. Native copy export supports documented basic mappings and blocks unsupported edits. Projects with recording-take history, custom timeline layers or moving canvas backgrounds are blocked to avoid losing data. Complex effects, group behavior, other schema versions and universal round-trip compatibility are not established. [Details](BORUMI-COMPATIBILITY.md). |
| Effects and tracking | Core effects, cursor paths and composition are independently implemented. Largest-face centering samples locally at up to 4 Hz and interpolates; it does not identify a person, and can switch, lag or fall back during occlusion. Cold preview tiles can briefly center. Segmentation preview is paused-frame. Rounded camera frames and shadows are editable and render in preview/export; unsupported corner shapes, native cursor artwork, easing and exact pixel parity still differ. |
| Speech and AI | Automatic local transcription is on by default. Explicit microphone provenance takes priority over overlapping system sound, even when quiet; this does not separate voices. Muted/zero-gain microphones permit fallback. Auto-cut/Visualize support whole-project or selected-scene proposals for review, not factual verification. Optional Claude analysis and other cloud adapters use the configured provider and its terms/costs. |
| MCP and recovery | There are 39 independent MCP tools, not another editor's protocol. Frame inspection uses committed state. Edit transactions expire after one hour and do not survive restart. Relink plans expire after 30 minutes; their guarded Undo is unavailable after service restart or a later edit. Recovery tools are excluded from in-app Claude chat. |
| Export | MP4/WebM/WAV and document formats are available. A 20-minute corrected export passed full decode/audio and sampled visual regressions, not all-frame native parity. Saved-version restart renders from the beginning; no chunk resume. Changed/missing sources block restart and changed tools require acknowledgment. Snapshots do not contain source media. |
| Desktop release | macOS 14+ Apple Silicon only. This prerelease is Apple Development signed, not notarized. An installed A→B→A cycle retained camera/mic/screen grants on one Mac; initial identity changes or OS revocation may still need consent. No automatic updater or hosted sharing/account system. |

Performance work includes viewport-limited timeline rendering, active-source decoding, cached analysis, chunked export and bounded undo. These choices do not prove SceneForge is faster than Borumi across workloads.

See [validation](VALIDATION.md) for precise completed checkpoints. Reports should use a minimal synthetic example when possible; project files, logs and screenshots may contain personal paths, transcript text and private footage.
